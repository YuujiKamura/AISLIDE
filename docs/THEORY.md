# 書き直しやすい図のセオリー

規制図は一回で決まらない。通行止め区間が延びる、看板セットを削る、施工箇所が増える、
人が線を引き直す。**書き直しが「意図を1つ変える → 影響する所だけ自動で追従」で済む**ことを
すべての設計判断の基準にする。

## 原則

### P1. 正本は「意図」、図はその投影
図形の座標そのものを正本にしない。正本は「何を・どこ基準で・なぜ置くか」という意図の記録で、
図形は意図から投影された結果。書き直しは意図を変えて投影し直すこと。
- 意図の正本はデッキ自身が持つ（スライドの**スピーカーノート**に manifest として保存）。
  デッキを複製すれば意図も付いてくる。人も読める・直せる。
- 各図形の代替テキストには「どの意図から生まれたか」（unit 名）だけを書く。

### P2. 置き場所は「基準からの相対」で持つ
看板・誘導員・注記は絶対座標ではなく**アンカー基準**で置く。
`at=Z1.E-50m`（通行止め Z1 の東端から 50m 手前）、`at=site:2+N10m`。
アンカー（区間の端・施工箇所・交差点）が動けば、従属物は自動で付いてくる。

### P3. 派生物は手で直さない
凡例（使っている看板だけ・番号は使用順に詰める）、看板の枚数、番号バッジ、マスク、DRC は
**配置から導出**する。人も AI も直接いじらない。`legend sync` が常に作り直す。
→ 「③と⑤を消す」は凡例を直すのではなく、③⑤を使う配置を外せば凡例から自然に消える。

### P4. 人の手直しは「上書き」として保存し、再投影で失わない
人がブラウザで生成物をドラッグしたら、その差分を**アンカーからのオフセット（override）**として
意図側に記録する。区間を延ばして再投影しても、人が寄せた位置関係は保たれる。

### P5. 単位には安定した名前を付ける
index（並び順）は削除のたびにずれる。各単位は人が読める名前で呼ぶ：
`Z1`（区間）、`Z1.E`（その東端）、`Z1.E.予告`（東端の予告セット）、`S2`（施工箇所2）。
コマンドは名前で指す。index は `list` 直後の一時的な指差しにだけ使う。

### P6. 1 コマンド = 1 単位、必ず戻せる
コマンドは 1 つの単位だけを書き換え、書込みはすべて undo 可能。消す前の段階として
`strike`（斜線で取消・下書き）→ `finalize`（清書で削除）を挟める。

### P7. 規則は部品と配置セットに埋め込む
コーン間隔・テーパー・予告看板の距離と枚数（FR-10 等）は、AI の判断ではなく単位の生成規則に持つ。
AI と人が決めるのは「区間の範囲」と「例外」だけ。

## 単位の階層

| 単位 | 名前例 | 中身 | 主な道具 |
|---|---|---|---|
| シート | `sheet` | 用紙・表題・凡例枠（レイアウト層＝掴めない） | `sheet title`, `pin` |
| 地図ビュー | `view` | 背景写真の位置と縮尺（georef） | `view fit / center / zoom` |
| 施工箇所 | `S1..` | 点＋番号 | `site add / move / rm` |
| 規制区間 | `Z1..` | 道路沿いの範囲（折れ線）、端 `E/W/N/S`、除外（交差点） | `zone add / extend / cut / adopt` |
| 配置セット | `Z1.E.予告` | 端ごとの予告看板・誘導員・バリケード。規則（FR-10 等）から生成 | `set apply rule= / set rm` |
| 部品 | `Z1.E.予告#1` | 看板1枚・誘導員1人・コーン列 | `nudge / move / strike / rm` |
| 凡例 | `legend` | 使用中の看板から導出・番号詰め | `legend sync`（手編集なし） |
| 注記 | `N1..` | 短い引出し（20 文字以内） | `note add / rm` |
| 人の描画 | `base` | タグ無し。読み取り専用 | `adopt <i> as zone Z1` 等で単位に昇格 |

## 書き直しの例（秋津町秋田 43）

1. 人が引いた赤線を区間に昇格：`zone adopt 36 as Z1`（東西）、`37..39` を `Z2..Z4`（南北の交差道路）
2. 規則を当てる：`set apply Z1 rule=FR-10` → 東端・西端に「④50m先工事中」を 1 枚ずつ
3. `legend sync` → 使っていない ③100m先・⑤徐行 は凡例から消え、番号は詰まる
4. 「東側もう 30m 延ばす」→ `zone extend Z1.E 30m` だけ。東の予告看板・誘導員は付いてくる
5. 人がブラウザで東の看板を少し北へ寄せた → `sync` で `Z1.E.予告#1` に override として記録。
   次に区間を変えても寄せた分は保たれる

## 実装順

1. manifest（ノート上の意図の正本）と単位名・名前での指定
2. アンカー相対の配置と override 記録（P2, P4）
3. `legend sync`（P3）
4. zone / set と規則（FR-10）（P7）
5. レイアウト層への `pin`（固定物）と `strike / finalize`
